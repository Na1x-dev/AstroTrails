# 🌠 AstroTrails

> Автономный веб-редактор для создания фотографий звездных треков в режиме «Кометы» (Comet Mode) прямо из ваших таймлапс-видео.

### 🔗 [Запустить AstroTrails в браузере (GitHub Pages)](https://na1x-dev.github.io/AstroTrails/)

---

## ✨ Основные особенности
- **Режим кометы нового поколения:** Использование нелинейных геометрических кривых для бесконечно длинного и плавного затухания хвостов звезд.
- **Экспорт в Оригинальном Качестве:** Рендеринг итогового изображения выполняется в 100% разрешении исходного видео (поддержка 4K UHD).
- **GPU-Оптимизация (Proxy-Preview):** Мгновенная цветокоррекция на 60 FPS за счет интеллектуального масштабирования превью-потока.
- **Интерактивное управление:** Регулировка ползунков с помощью кнопок точного шага `+` / `-` и колесика мыши.
- **Абсолютная автономность:** Работает полностью в браузере (Client-Side) без серверов, баз данных и внешних зависимостей.
- **Mobile Responsive:** Полная адаптация интерфейса для удобного использования на экранах смартфонов и планшетов.

## 🛠️ Панель инструментов постобработки
- **Трассы:** Настройка крутизны экспоненциального затухания хвоста кометы.
- **Экспозиция:** Тонкая регулировка яркости и контрастности кадра.
- **Гамма:** Коррекция полутонов для создания глубокого, абсолютно черного ночного неба.
- **RGB микшер:** Раздельное управление Красным, Зеленым и Синим каналами для проявления туманностей и млечного пути.

## 🚀 Быстрый старт на локальном ПК
1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Na1x-dev/AstroTrails.git
   ```
2. Откройте файл `index.html` в любом современном браузере.
3. Перетащите ваше склеенное видео астрофотографии в центр экрана!
