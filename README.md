# 🌠 AstroTrails

> Автономный веб-редактор для создания фотографий звездных треков в режиме «Кометы» (Comet Mode) прямо из ваших таймлапс-видео.

### 🔗 [Запустить AstroTrails в браузере (GitHub Pages)](https://na1x-dev.github.io/AstroTrails/)

---

## ✨ Основные особенности
- **Режим кометы нового поколения:** Использование нелинейных геометрических кривых для бесконечно длинного и плавного затухания хвостов звезд.
- **Потоковая обработка видео:** кадры сразу смешиваются на одном холсте; отдельные кадры не накапливаются в оперативной памяти. Для стабильности размер холста ограничен длинной стороной 1440 px на мобильных устройствах и 2048 px на компьютерах.
- **GPU-Оптимизация (Proxy-Preview):** Мгновенная цветокоррекция на 60 FPS за счет интеллектуального масштабирования превью-потока.
- **Интерактивное управление:** Регулировка ползунков с помощью кнопок точного шага `+` / `-` и колесика мыши.
- **Абсолютная автономность:** Работает полностью в браузере (Client-Side) без серверов, баз данных и внешних зависимостей.
- **Mobile Responsive:** Адаптация интерфейса для удобного использования на экранах смартфонов и планшетов.

## 🛠️ Панель инструментов постобработки
- **Трассы:** Настройка крутизны экспоненциального затухания хвоста кометы.
- **Экспозиция:** Тонкая регулировка яркости и контрастности кадра.
- **Гамма:** Коррекция полутонов для создания глубокого, абсолютно черного ночного неба.
- **RGB микшер:** Раздельное управление Красным, Зеленым и Синим каналами для проявления туманностей и млечного пути.

## 🚀 Быстрый старт на локальном ПК
1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Na1x-dev/AstroTrails.git
   ```
2. Откройте файл `index.html` в любом современном браузере.
3. Перетащите ваше склеенное видео астрофотографии в центр экрана!


## Дополнительные возможности (ветка разработки)

- **Наложение фотографий:** можно выбрать до 300 изображений; они сортируются по имени и последовательно смешиваются в одну композицию в режиме Lighten. Размер холста ограничен 4096 px по длинной стороне для снижения риска переполнения памяти.
- **Объединение видео:** клипы декодируются и записываются заново в один WebM-файл через MediaRecorder. Это не побайтовая склейка MP4. Текущая реализация экспортирует видеоряд без звуковых дорожек; MP4 пока не создаётся.
- **Мобильный интерфейс:** убрано принудительное отключение масштабирования, адаптирована компоновка и увеличены зоны нажатия.

- **Световые следы без кэша кадров:** видео обрабатываются по одному клипу за раз; при наличии `requestVideoFrameCallback` кадры синхронизируются с декодером, а в памяти остаётся только итоговая композиция и буфер превью. Изменение прозрачности требует повторного запуска обработки кнопкой «Пересчитать треки».
